# Spice Python SDK v3.1.0

## What's New

### 🎯 Parameterized Queries

The SDK now supports parameterized queries using ADBC (Arrow Database Connectivity). This is the recommended approach for queries with user input to prevent SQL injection attacks.

```python
from spicepy import Client

client = Client()

# Query with automatic type inference
reader = client.query_with_params(
    "SELECT trip_distance, fare_amount FROM taxi_trips WHERE trip_distance > $1 LIMIT 10",
    [5.0]
)

for batch in reader:
    print(batch.to_pandas())
```

### 📦 Typed Parameters

For precise control over Arrow types, use tuples with PyArrow types:

```python
import pyarrow as pa
from spicepy import Client

client = Client()

# Use (value, pa.DataType) tuples for explicit types
reader = client.query_with_params(
    "SELECT * FROM table WHERE id = $1 AND amount = $2",
    [(123, pa.int32()), (99.99, pa.float64())]
)
```

**Supported parameter types with automatic type inference:**

- **Integers**: `int` → `Int64`
- **Floating point**: `float` → `Float64`
- **Strings**: `str` → `String`
- **Boolean**: `bool` → `Boolean`
- **Binary**: `bytes` → `Binary`
- **Null values**: `None` → `Null`
- **Decimal**: `Decimal` → `Decimal128`
- **Datetime**: `datetime` → `Timestamp`
- **Date**: `date` → `Date32`
- **Time**: `time` → `Time64`
- **Duration**: `timedelta` → `Duration`

**Explicit type specification:**

Use `(value, pa.DataType)` tuples when you need precise control:

```python
import pyarrow as pa

params = [
    (42, pa.int32()),           # int32 instead of default int64
    (3.14, pa.float32()),       # float32 instead of default float64
    ("hello", pa.large_string()) # large_string instead of string
]
```

## 🔒 Security Benefits

Parameterized queries provide protection against SQL injection attacks:

```python
# ❌ Vulnerable to SQL injection
user_id = get_user_input()  # Could be: "1 OR 1=1"
reader = client.query(f"SELECT * FROM users WHERE id = {user_id}")

# ✅ Safe from SQL injection
reader = client.query_with_params(
    "SELECT * FROM users WHERE id = $1",
    [user_id]
)
```

## Installation

Install with the optional `params` extra to enable parameterized query support:

```bash
pip install "spicepy[params]"
```

The optional dependencies are:

- `adbc-driver-flightsql>=1.0.0`
- `adbc-driver-manager>=1.0.0`

## Requirements

- **Python 3.9+** (minimum supported version)

None. This release is fully backward compatible with v3.0.0.

## API Reference

### `Client.query_with_params(sql, params)`

Execute a parameterized SQL query using ADBC.

**Parameters:**

- `sql` (str): SQL query with positional placeholders ($1, $2, etc.)
- `params` (list[Any]): List of parameter values. Can be plain Python values (type inferred) or `(value, pa.DataType)` tuples for explicit types.

**Returns:**

- `pyarrow.RecordBatchReader`: Arrow RecordBatchReader with query results

**Raises:**

- `ImportError`: If ADBC driver is not installed
- `TypeError`: If a parameter type is not supported

### `infer_arrow_type(value)`

Infer the appropriate PyArrow type for a Python value.

**Parameters:**

- `value` (Any): Python value to infer type from

**Returns:**

- `pa.DataType`: The inferred PyArrow data type

**Raises:**

- `TypeError`: If the value type is not supported
