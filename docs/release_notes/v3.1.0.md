# Spice Python SDK v3.1.0

## What's New

### 🎯 Parameterized Queries

The SDK now supports parameterized queries using ADBC (Arrow Database Connectivity). This is the recommended approach for queries with user input to prevent SQL injection attacks.

```python
from spicepy import Client

client = Client()

# Query with automatic type inference
reader = client.query_with_params(
    "SELECT trip_distance, fare_amount FROM taxi_trips WHERE trip_distance > $1 LIMIT 10",
    [5.0]
)

for batch in reader:
    print(batch.to_pandas())
```

### 📦 Typed Parameters

For precise control over Arrow types, use the `Param` class with explicit type annotations:

```python
from spicepy import Client, Param

client = Client()

reader = client.query_with_params(
    "SELECT * FROM table WHERE id = $1 AND amount = $2",
    [Param.int32(123), Param.float64(99.99)]
)
```

**Supported parameter types with automatic type inference:**

- **Integers**: `int` → `Int64`
- **Floating point**: `float` → `Float64`
- **Strings**: `str` → `String`
- **Boolean**: `bool` → `Boolean`
- **Binary**: `bytes` → `Binary`
- **Null values**: `None` → `Null`
- **Decimal**: `Decimal` → `Decimal128`
- **Datetime**: `datetime` → `Timestamp`
- **Date**: `date` → `Date32`
- **Time**: `time` → `Time64`
- **Duration**: `timedelta` → `Duration`

**Typed parameter constructors:**

- **Integers**: `Param.int8()`, `Param.int16()`, `Param.int32()`, `Param.int64()`, `Param.uint8()`, `Param.uint16()`, `Param.uint32()`, `Param.uint64()`
- **Floating point**: `Param.float16()`, `Param.float32()`, `Param.float64()`
- **Strings**: `Param.string()`, `Param.large_string()`
- **Binary**: `Param.binary()`, `Param.large_binary()`, `Param.fixed_size_binary()`
- **Boolean**: `Param.bool_()`
- **Temporal**: `Param.date32()`, `Param.date64()`, `Param.time32()`, `Param.time64()`, `Param.timestamp()`, `Param.duration()`
- **Decimals**: `Param.decimal128()`, `Param.decimal256()`
- **Null**: `Param.null()`
- **Generic**: `Param.of(value, arrow_type=None)`

## 🔒 Security Benefits

Parameterized queries provide protection against SQL injection attacks:

```python
# ❌ Vulnerable to SQL injection
user_id = get_user_input()  # Could be: "1 OR 1=1"
reader = client.query(f"SELECT * FROM users WHERE id = {user_id}")

# ✅ Safe from SQL injection
reader = client.query_with_params(
    "SELECT * FROM users WHERE id = $1",
    [user_id]
)
```

## Installation

Install with the optional `params` extra to enable parameterized query support:

```bash
pip install "spicepy[params]"
```

The optional dependencies are:
- `adbc-driver-flightsql>=1.0.0`
- `adbc-driver-manager>=1.0.0`

## Requirements

- **Python 3.9+** (minimum supported version)

## Breaking Changes

None. This release is fully backward compatible with v3.0.0.

## API Reference

### `Client.query_with_params(sql, params)`

Execute a parameterized SQL query using ADBC.

**Parameters:**
- `sql` (str): SQL query with positional placeholders ($1, $2, etc.)
- `params` (list[Any]): List of parameter values (can be plain Python values or Param instances)

**Returns:**
- `pyarrow.RecordBatchReader`: Arrow RecordBatchReader with query results

**Raises:**
- `ImportError`: If ADBC driver is not installed
- `TypeError`: If a parameter type is not supported

### `Param` class

A query parameter with optional explicit Arrow type.

**Factory Methods:**
- `Param.int8(value)`, `Param.int16(value)`, `Param.int32(value)`, `Param.int64(value)`
- `Param.uint8(value)`, `Param.uint16(value)`, `Param.uint32(value)`, `Param.uint64(value)`
- `Param.float16(value)`, `Param.float32(value)`, `Param.float64(value)`
- `Param.string(value)`, `Param.large_string(value)`
- `Param.binary(value)`, `Param.large_binary(value)`, `Param.fixed_size_binary(value, size)`
- `Param.bool_(value)`
- `Param.date32(value)`, `Param.date64(value)`
- `Param.time32(value, unit)`, `Param.time64(value, unit)`
- `Param.timestamp(value, unit, tz)`
- `Param.duration(value, unit)`
- `Param.decimal128(value, precision, scale)`, `Param.decimal256(value, precision, scale)`
- `Param.null()`
- `Param.of(value, arrow_type=None)`
