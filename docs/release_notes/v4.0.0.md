# Spice Python SDK v4.0.0

The v4.0.0 release introduces a lazy DataFrame API and expression DSL, adds search, runtime status, active-query management, and mTLS support, modernizes the runtime requirements, and bumps core dependencies to their latest major versions.

## Highlights

### 🧮 DataFrame API

A new `SpiceDataFrame` lazy query builder compiles to SQL and executes against the runtime over the existing Arrow Flight transport. There is no client-side execution — operations are nested as subqueries and flattened by the DataFusion optimizer.

```python
from spicepy import Client, col
from spicepy import functions as F

client = Client()

result = (
    client.table("taxi_trips")
    .filter(col("trip_distance") > 1.0)
    .group_by(col("payment_type"))
    .aggregate(
        F.count().alias("n"),
        F.sum(col("total_amount")).alias("revenue"),
        F.avg(col("trip_distance")).alias("avg_distance"),
    )
    .sort(col("revenue").desc())
    .limit(10)
    .to_pandas()
)
```

New entry points on `Client`:

- `client.table(name)` — DataFrame over an existing table
- `client.sql(query)` — DataFrame wrapping an arbitrary SQL query
- `client.from_arrow(table)` / `client.from_pandas(df)` / `client.from_pydict(data)` — DataFrame from in-memory data via inline `VALUES`

DataFrame operations include `select`, `with_column(s)`, `drop`, `rename`, `cast`, `filter`/`where`, `limit`, `head`, `sort`/`order_by`, `distinct`, `union`, `intersect`, `except_`, `join`, `cross_join`, `group_by(...).aggregate(...)`, `schema`, `explain`, `to_sql`, and materializers `collect`/`to_arrow`/`to_pandas`/`to_polars`/`to_pylist`/`to_pydict`/`count`/`show`.

### 🧱 Expression DSL

`Expr` is the new expression type, built with `col(name)`, `lit(value)`, or any function in `spicepy.functions`. Operators (`+ - * / % == != < <= > >= & | ~`) return new `Expr`s so expressions compose without evaluating.

```python
from spicepy import col, lit, case
from spicepy import functions as F

predicate = (col("trip_distance") > 1.0) & col("fare_amount").is_not_null()

bucket = (
    case()
    .when(col("total_amount") < 10, lit("small"))
    .when(col("total_amount") < 50, lit("medium"))
    .otherwise(lit("large"))
    .alias("bucket")
)
```

`spicepy.functions` covers common DataFusion built-ins: aggregates (`sum`, `avg`, `count`, `count_distinct`, `min`, `max`, `stddev`, `variance`, `median`, `approx_distinct`, `array_agg`), math (`abs`, `round`, `ceil`, `floor`, `sqrt`, `power`, `ln`, `log`, `exp`), strings (`lower`, `upper`, `length`, `trim`, `concat`, `substr`, `replace`, `regexp_match`, `starts_with`, `ends_with`), date/time (`now`, `current_date`, `current_timestamp`, `date_trunc`, `date_part`, `extract`), null/control flow (`coalesce`, `nullif`, `ifnull`, `case`), and window functions (`row_number`, `rank`, `dense_rank`, `percent_rank`, `cume_dist`, `lag`, `lead`, `first_value`, `last_value`, `nth_value`).

### 📤 Typed query helpers

`Client` now exposes one-shot helpers that materialize a query in the shape you want — each accepts `params=` and `timeout=`:

- `client.query_arrow(sql)` → `pyarrow.Table`
- `client.query_pandas(sql)` → `pandas.DataFrame`
- `client.query_polars(sql)` → `polars.DataFrame` (requires `spicepy[polars]`)
- `client.query_pylist(sql)` → `list[dict]`
- `client.query_pydict(sql)` → `dict[str, list]`
- `client.query_batches(sql)` → streaming iterator of `pyarrow.RecordBatch`

### 🔎 Catalog introspection

```python
client.catalogs()
client.schemas(catalog="spice")
client.tables(schema="public")
client.describe("taxi_trips")
client.get_schema("SELECT * FROM taxi_trips")
client.explain("SELECT * FROM taxi_trips", analyze=True)
client.show("SELECT * FROM taxi_trips", n=20)
```

### 💾 Writers

Stream query results directly to a file:

```python
client.write_parquet("SELECT * FROM taxi_trips", "trips.parquet")
client.write_csv("SELECT * FROM taxi_trips", "trips.csv")
client.write_json("SELECT * FROM taxi_trips", "trips.ndjson")  # newline-delimited
```

### 🎯 Parameterized Queries

Parameterized queries (introduced in v3.1.0) are now available across every query helper via `params=`, in addition to `client.query_with_params(sql, params)`. Use positional `$1`, `$2`, … placeholders.

```python
import pyarrow as pa

table = client.query_arrow(
    "SELECT * FROM taxi_trips WHERE trip_distance > $1 AND fare_amount > $2",
    params=[5.0, (20.0, pa.float64())],
)
```

Requires the `params` extra: `pip install "spicepy[params] @ git+https://github.com/spiceai/spicepy@v4.0.0"`.

### 🔍 Search

`client.search` runs vector, keyword, or hybrid search against the runtime's `/v1/search` endpoint. Datasets need an embedding column and a loaded embedding model; supplying `keywords` adds a lexical pass that the runtime combines with the vector scores into a hybrid ranking.

```python
result = client.search(
    "tokyo plane tickets",
    datasets=["app_messages"],
    limit=3,
    additional_columns=["timestamp"],
)
```

### 🩺 Runtime status

- `client.is_ready()` — single boolean readiness check (`/v1/ready`)
- `client.runtime_status()` — per-component status for `http`, `flight`, `metrics`, and `opentelemetry` (`/v1/status`)

### 🛑 Active query management

- `client.list_active_queries()` — the queries the runtime is currently executing
- `client.cancel_active_query(query_id)` — cancel one of them

### 🔐 mTLS client certificates

`Client` accepts `tls_client_certificate` and `tls_client_key` (PEM file paths, provided together) to authenticate with runtimes configured for mutual TLS. mTLS is an [Enterprise](https://docs.spice.ai/docs/enterprise) feature of the Spice.ai runtime.

### 📓 Notebook & Arrow interop

- `SpiceDataFrame` renders as an HTML table in Jupyter (`_repr_html_`) and exports zero-copy to any Arrow consumer via the Arrow PyCapsule interface (`__arrow_c_stream__`)
- Column selection with `df["col"]` / `df[["a", "b"]]`, plus `intersect`/`except_` set operations and `unnest`, joins, and `describe`
- Array & struct type support and a substantially expanded `spicepy.functions` module (array/struct constructors and accessors, additional math, string, and datetime functions)

## Breaking Changes

- **Spice.ai Cloud endpoints are now region-specific.** The legacy region-agnostic hostnames `grpc+tls://flight.spiceai.io` and `https://data.spiceai.io` are no longer valid. Use `grpc+tls://<region>-prod-aws-flight.spiceai.io` and `https://<region>-prod-aws-data.spiceai.io` (e.g. `us-east-1`, `us-west-2`, `eu-west-1`). `config.DEFAULT_FLIGHT_URL` and `config.DEFAULT_HTTP_URL` have been updated accordingly.
- **`Client(http_url=...)` now defaults to the local runtime** (`http://localhost:8090`), matching the existing `flight_url` default. Previously it defaulted to the (now broken) cloud HTTP hostname.
- **Minimum Python version is now 3.11** (previously 3.8).
- **Core dependency major bumps:**
  - `pyarrow >= 24.0.0`
  - `pandas >= 3.0.3`
  - `certifi >= 2026.4.22`
  - `requests >= 2.34.0`
- **Empty `api_key` strings are now treated the same as `None`.** Authentication is only attempted when an API key is actually provided. ([#133](https://github.com/spiceai/spicepy/pull/133))
- Packaging migrated to PEP 621 metadata in `pyproject.toml`. The published wheel now declares the `params` and `polars` extras.

## Upgrading from 3.x

**Spice.ai Cloud: update your connection URLs.** The legacy hostnames (`grpc+tls://flight.spiceai.io`, `https://data.spiceai.io`) were retired server-side, so existing cloud connection code no longer connects on *any* SDK version — including code copied from the 3.x README. Point the client at your app's region (e.g. `us-east-1`, `us-west-2`, `eu-west-1`):

```python
# Before (3.x — no longer connects)
client = Client(api_key="API_KEY", flight_url="grpc+tls://flight.spiceai.io")

# After
client = Client(
    api_key="API_KEY",
    flight_url="grpc+tls://us-east-1-prod-aws-flight.spiceai.io",
    http_url="https://us-east-1-prod-aws-data.spiceai.io",
)
```

**`Client()` with no URLs now consistently targets a local runtime.** In 3.x, a bare `Client()` used the local runtime for Flight queries but the (now retired) cloud host for HTTP calls such as `refresh_dataset`. Both now default to local (`grpc://localhost:50051`, `http://localhost:8090`). Pass explicit URLs to reach Spice.ai Cloud.

**Runtime requirements:** Python 3.11+ (3.9/3.10 dropped). Dependency floors moved to current majors — upgrade pandas to 3.x and pyarrow to 24+ in your environment before (or together with) spicepy.

Everything else is additive: existing `query()`, `query_with_params()`, and `refresh_dataset()` code runs unchanged.

## Installation

`spicepy` is not published on PyPI under that name; install directly from GitHub:

```bash
pip install git+https://github.com/spiceai/spicepy@v4.0.0

# Parameterized queries
pip install "spicepy[params] @ git+https://github.com/spiceai/spicepy@v4.0.0"

# Polars output
pip install "spicepy[polars] @ git+https://github.com/spiceai/spicepy@v4.0.0"
```
